# 岁月记录助手 · 使用说明（v0.9.15）

> 这份说明写给**第一次用的人**。按顺序做一遍，就能把一位长辈的一生整理成一本能翻、能听、能带走的档案。
>
> 不需要装数据库，不需要懂技术。Windows 上双击一个文件，安卓上装一个 APK。

---

## 一、先把它跑起来

### Windows

1. 把 `MyLife-v0.9.15-windows.exe` 拷到电脑上一个你找得到的文件夹（比如「岁月记录助手」）。
2. **双击**它，会自动打开浏览器；同时会有一个黑色命令行窗口，**别关，关了程序就停了**。
3. 想彻底卸载：删掉整个文件夹就行，不会在别处留东西。

> 如果提示"Windows 保护你的电脑"：点**更多信息 → 仍要运行**（程序没做代码签名，这是首次运行的正常提示）。
>
> 如果 4321 端口被别的软件占了：在地址栏输入 `cmd` 回车，执行 `set PORT=4401 && MyLife.exe`。

### 安卓

1. 把 `MyLife-v0.9.15-android.apk` 传到手机，点开安装；提示"未知来源"时允许一次即可。
2. 装完打开，进「设置 → 关于」能核对版本号 **v0.9.15**，确认装对了。

---

## 二、第一次用：三步

1. **注册**：手机号 + 密码 + 验证码（演示版固定填 `1234`）。
   每个账号一个**独立数据库**，家里几个人各注册各的，互相看不到。
2. **说一段**：点「点一下，开始说」，说完再点一下停下；**先按播放条听一遍**，
   听得到声音再点「存为一条讲述」，最后点「转成文字」。
3. **生成档案**：材料够了就点「整理进目录」，系统按人生阶段排好目录；
   想自己写也行——「自己加一章」或直接打字。

> 录音没声音怎么办（手机）：确认麦克风权限是"仅使用期间允许"，
> 检查手机壳有没有挡住底部麦克风孔；设置页有「麦克风诊断」可自检。

## 三、AI 怎么用（不配也能用）

不填任何 Key，程序照样能排目录、出档案（章节名按年份和内容自动生成）。

想让 AI 帮忙起章名、画插图、配音、作歌，就在**设置 → 模型来源**填一个 API Key。
推荐**硅基流动**（国内可直连，有常驻免费模型）或**智谱 bigmodel**（注册送 2000 万
Tokens 大礼包，Flash 系列永久免费）；填完点「测试」，通过即可。

> 💡 **注册入口（推荐收藏）**：
> - 硅基流动：https://cloud.siliconflow.cn/i/oSZ7RcMc （手机号 + 验证码即注册成功；「API 密钥」页新建后复制，粘贴到程序里就行）
> - 智谱 bigmodel：https://www.bigmodel.cn/invite?icode=WAwAU1lS%2F%2F6gb1nF7hLtY1wpqjqOwPB5EXW6OL4DgqY%3D （邀请注册送 2000 万 Tokens；接口地址填 `https://open.bigmodel.cn/api/paas/v4`）

填一个 Key 会自动配好几个环节。**想作歌要再加一家**（阶跃星辰，限时免费；或 Mureka，按首计费）——
硅基流动目前没有音乐模型。

**对话页顶部能直接换模型**：聊天 / 看图说话 / 画图 / 做视频 / 图片识字 / 语音转文字 /
合成语音 / 写歌·作曲，八种用途在一个框里切。切档只列这个用途能用得成的模型，
不会让你拿"写字的模型"去画图。

> AI 生成的内容都会标明「AI 生成」。声音克隆默认关闭。

## 四、几个最常用的动作

| 想做什么 | 在哪 |
| --- | --- |
| 改一段文字、换顺序 | 章节页每段下面的「改 / ↑ / ↓」 |
| 一段配好几张照片 | 段落上的「＋图」，可多选 |
| 给照片写"哪一年、在哪儿、什么事" | 章节页「本章照片」→ 每张下面的说明 |
| 挪到别的章 | 段落上的「归章 / 换章」 |
| 整本读一遍 / 从头朗读 | 章节页朗读，会先列出各章字数让你选从哪章开始 |
| 做成书 | 「导出」→ Word / PDF / PPT / 印刷版网页，**导出前可预览** |
| 做成片子 | 章节页「做短片」：分镜 → 配音 → 配乐 → 字幕，出竖屏 mp4 |
| 作一首自己的歌 | 对话页 →「写歌·作曲」→「AI 作曲演唱」，选曲风、可填词，也可只要伴奏 |
| 删掉不想要的片子/歌 | 档案首页「合成的片子」「写的歌」每条右侧红色「删除」 |

**短片、AI 生视频、AI 作歌只在电脑上做**（要 ffmpeg 与外链落盘），手机上会自动禁用并提示。

## 五、数据在哪、怎么备份

| 平台 | 数据位置 |
| --- | --- |
| Windows | 程序文件夹下 `data\users\<账号号>\`（`archive.db` + `files\`） |
| 安卓 | 应用私有目录 `files\users\<账号号>\` |

**只要备份 `data` 目录就够了**。更省事的办法是在首页「导出」，整本档案（文字 + 照片 + 录音 + 成片）
打包成一个文件，换机时「导入」即可还原。

导入时如果撞上同名或同编号的档案，会先问你：**覆盖 / 另存副本 / 取消**——不会再默默多出一本。
**Word 文档也能直接导入**（自己导出的和别人写的都认，标题 1 分章、图片一起进来）。

## 六、忘了密码怎么办

- 有密保问题：登录页「找回密码」。
- 都没有：用 `reset-password.bat`（源码目录下的 `tools/reset-password.js`）离线重置，
  **只改密码，不动档案内容**。

## 七、常见问题

- **黑窗口能关吗？** 不能，那是程序本体；最小化即可。
- **数据会不会传到网上？** 不会。程序只在自己电脑 / 手机上跑，只有你主动点"调 AI"时才联网，
  而且只把那一段内容发给模型服务商，API Key 永远不下发到界面。
- **老手机能用吗？** 安卓 6 以上可以。前端刻意写成很老的语法，就是为了老机器不白屏。
- **能多人同时用一台电脑吗？** 可以，各注册各的号，数据物理隔离。
- **手机上不能作歌 / 合成短片？** 是的，这两件事要 ffmpeg，请在电脑上做。
