# 《岁月记录助手》功能优化方案

> 文档版本：v1.0 ｜ 2026-10-29
> 配套文档：《竞品分析与风险评估.md》《运营获客策划书.md》
> 方针：**低成本运营，开发成本为零（自己写）、运营成本为零（架构已定）、资源成本为零（云资源零依赖），集中精力借竞品之长补己之短，为商业化打地基。**

---

## 一、优化总原则

从竞品与历史项目调研中提炼出四条产品铁律，所有优化围绕它们展开：

1. **素材门槛决定一切**：6,800 万老人想要回忆录、实现不到 3%，卡点从来不是"不想记"，是"记录太累"——每一次优化都要降低录入门槛
2. **留存靠日常，成书靠节点**：档案是低频大工程，必须配一条高频小习惯的素材管道（白守AI 已验证：随手记→AI 归纳模式成立）
3. **访谈比记录更有效**：海外最佳实践（Remento/StoriedLife/慰康）共同点是"AI 追问式访谈"——老人不会写回忆录，但都会聊天
4. **信任是唯一长期壁垒**：行业乱象（永久保存要买保险、两年不登录删数据）留出"干净品牌"空位，所有设计向"数据主权+明码标价"看齐

## 三、新增功能详设

### 3.1 素材流（P0，预计 3–5 天）——留存抓手

```
首页新增「随手记」入口（30 秒零门槛）
  ├─ 写一句 / 拍一张 / 说一段（复用现有三种录入）
  ├─ 不强制选档案、不强制写年份——先进"素材箱"
  └─ 每周日 AI 自动归纳：「本周妈妈讲了 3 件事：…」
       ├─ 一键收录 → 询问归入哪份档案哪个年代（AI 建议年份）
       └─ 忽略/修改后再收
```

- 数据结构：entries 表加 `status`（inbox/adopted/discarded）字段即可，动一小步
- 商业意义：日活抓手 + 内容飞轮（素材越多→传记越厚→越不舍得迁移）

### 3.2 AI 访谈模式（P0，预计 5–7 天）——内容质量抓手

- 对话页新增「访谈」入口：AI 按档案已有信息+年代模板提问（"您 1962 年出生在石城，还记得小时候家里房子是什么样的吗？"），**追问至少两层细节**（Remento 式）
- 全程录音，结束后 AI 出"访谈纪要"：转写+分主题整理，一键拆成多条档案条目
- 内置问题库 v1：先做 100 题（童年/求学/婚恋/生育/工作/晚年/时代记忆七大类）
- 这是对竞品"人工上门访谈"的 AI 平替——慰康靠两次上门访谈撑起 2880 元客单，我们把访谈免费化

### 3.3 每周一题（P1，预计 2 天）——触达抓手

- 每周一推送一个记忆话题（小程序订阅消息 + 公众号同步）
- 用户点击直接进入素材流录入——把"想不起来记什么"变成"每周有个钩子"

### 3.4 数据承诺书 + 透明化（P0，预计 1 天）

- 设置页常驻「我们的承诺」：①数据存在你自己手机里 ②随时完整导出 ③绝不在未付费承诺的情况下删数据 ④未来收费全部明码标价
- 这是针对行业乱象的品牌差异化，成本一小时，信任价值长期

### 3.5 备份格式 v1 定稿（P0，预计 2 天）

- backup-schema v1：版本号+档案+条目（含素材流状态）+照片（可选包）+模型配置（可脱敏）
- 网页版↔小程序互通；为云备份、成书、纪念馆转制提供统一底座

## 四、体验优化（既有功能打磨）

| 项 | 内容 | 量级 |
|---|---|---|
| 导出长图 | 小程序章节渲染长图存相册（商业方案的 Phase 0 三件套之一） | 3 天 |
| 分享卡片 | 档案封面+金句摘段的自定义分享图 | 2 天 |
| 大字模式 | 全局字号 1.25x/1.5x 切换，适老化补全 | 2 天 |
| 年份纠错 | AI 建议年份 + 用户确认（素材流配套） | 1 天 |
| 翻书预览 | 成书前用翻书组件预览（感动时刻，截图传播点） | 3 天 |

## 五、明确不做（防发散）

- ❌ 电影/电视剧制作（内容行业，成本结构不同）
- ❌ 独立日记 App（素材流已是日记，且和档案打通）
- ❌ 社交/公共广场（纪念与档案都要求私密克制）
- ❌ 自建模型/本地大模型（永远吃模型平台的能力红利）
- ❌ Phase 0 期间任何服务端功能（保持零运营成本铁律）

## 六、排期总览（约 6 周开发量，单人+AI 辅助）

| 周 | 交付 |
|---|---|
| W1 | 素材流 + 数据承诺书 |
| W2 | AI 访谈模式 + 问题库 v1 |
| W3 | 备份格式 v1 定稿 + 导出长图 |
| W4 | 分享卡片 + 每周一题 |
| W5 | 大字模式 + 年份纠错 |
| W6 | 翻书预览 + 整体回归测试（835 项断言基础上扩充） |

> 每项交付即更新测试脚本；六周后产品完成度对标竞品全线（含 399 元档小鹿光年）且保持免费。
