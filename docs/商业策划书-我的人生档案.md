# 《岁月记录助手》商业策划书

> 项目口号：**给爸妈建一份档案，把一生的故事留给全家。**  
> 文档版本：v1.0 ｜ 2026-10-29 ｜ 面向潜在合作方/投资人

---

## 一、项目概述

### 1.1 一句话定位

一款帮家庭记录长辈人生故事的 AI 档案工具：子女用手机帮父母**录音说话、翻拍老照片**，AI 自动转文字、润色成章、看图写说明，最终整理成**按年份分章的个人传记**，可导出成册。

### 1.2 为什么做这个

- 中国 60 岁以上人口约 3.1 亿（占比 22%），每年大量家庭经历"人走了，故事也带走了"的遗憾
- 人工回忆录服务客单价数千至数万元，绝大多数家庭消费不起
- 大模型把"访谈、整理、成文"的成本降到近零——**这是 AI 落地家庭情感场景的最佳切口之一**
- 子女→家庭群→亲戚的传播链路天然顺畅，且与运营者名下公众号「笑卿微道」可互相导流

### 1.3 产品现状（已实现，非 PPT 阶段）

| 端           | 形态                 | 状态            |
| ----------- | ------------------ | ------------- |
| Windows 桌面版 | 单文件 EXE（147MB，免安装） | ✅ v0.9.16，已发布 |
| 网页版         | 纯静态站点，数据存浏览器       | ✅ 已上线云端       |
| 安卓版         | APK 安装包            | ✅ 已发布         |
| 微信小程序       | 原生小程序，5 页面 MVP     | ✅ 代码完成，待发布    |

核心功能已全部跑通：档案管理、按年份自动分章、文字/录音（AI 转文字）/照片三种录入方式、AI 看图写说明、AI 助手流式对话（润色讲述、起章节名）、AI 作曲（桌面版）、多平台模型接入（硅基流动/智谱/阶跃星辰，均有免费额度）。

**工程质量**：40 个自动化测试脚本、835 项断言；三端同构架构（同一套业务逻辑跨端复用）。

### 1.4 完整生命周期愿景

**生前是档案工具（免费获客）→ 人生节点出册出片（第一波付费）→ 身后是数字纪念馆（20 年长尾订阅）**——一个用户的商业价值覆盖两代人。

人在世时，这是记录人生的档案工具；身后，档案自动转为家族数字纪念馆，供亲友追思瞻仰，数据持续保存维护。它对标的是线下骨灰存放柜数万至数十万元的费用——我们提供"数字化安葬"：一个承载一生故事的纪念空间，二十年只收几千元。丧事简办是政策方向，数字纪念是趋势所向。

## 二、市场分析

### 2.1 需求真实性

- **强情感需求**：给父母留口述史是"来不及做会后悔"的事，决策门槛低、传播意愿强
- **付费已被验证**：美国 StoryWorth（每周提问→年终成书，订阅约 99 美元/年）已验证"家庭传记"付费模式；国内人工回忆录服务收费 3,000–50,000 元/册，证明高净值需求存在
- **空白带明显**：高价人工服务与"完全没人做"之间，缺一个 AI 驱动、普通家庭用得起的工具——这正是本项目的位置

### 2.2 目标用户

| 人群                 | 场景     | 特征                    |
| ------------------ | ------ | --------------------- |
| 30–55 岁子女（决策者/付费者） | 给父母建档  | 有支付能力，主动传播者           |
| 55–80 岁长辈（使用者）     | 讲述、看册子 | 需要极简交互（本产品按"老人能上手"设计） |
| 家族成员（扩散者）          | 家庭群传阅  | 免费传播节点                |

### 2.3 竞争格局

| 类型         | 代表     | 短板              | 本项目差异化         |
| ---------- | ------ | --------------- | -------------- |

## 三、核心竞争力与技术壁垒

### 3.1 "零边际成本"架构（本项目的根本护城河）

行业普遍做法是自建服务器+自付模型费，用户越多亏越多。本项目架构反其道而行：

1. **数据全部存用户设备本地**（IndexedDB / wx.storage），云端零存储成本
2. **AI 直连模型平台**，用户填自己的免费 Key（硅基流动/智谱均有常驻免费模型），平台零模型成本
3. **服务端只在云备份/支付时才需要**，且备份用对象存储（约 0.1 元/GB/月），1 万用户规模月成本仅数十元

> 结论：**在日活 1,000 以下，项目运行成本为 0 元/月。** 这是个人开发者敢"免费养用户"的底气，也是投资方最该关注的成本结构优势。

### 3.2 其他壁垒

- **三端同构代码**：一套业务逻辑覆盖 EXE/网页/APK/小程序，新功能一次开发四端生效
- **适老化设计经验**：界面按"老人能看懂上手"标准打磨，配有图文手册
- **完整交付链**：从录入到按年份成章到导出成册，闭环已打通

## 四、商业模式（三阶段）

### 阶段一：养用户期（当前 → 日活 1,000）——零成本，全免费

- 不限额、不收费、不上服务端，极致打磨留存与传播
- 成本：域名 + 备案约 100 元/年，其余为 0
- 核心动作：小程序发布、公众号内容营销、分享链路优化

### 阶段二：商业化启动期（日活 > 1,000）

触发条件达到后 30 天内完成：注册个体户（约 3 天）→ 微信认证（30 元/年）→ 开通微信支付 → 上线统一后端（轻量服务器 + 对象存储）。

| 收入线           | 定价（拟）              | 说明                          |
| ------------- | ------------------ | --------------------------- |
| 云备份/多设备同步     | 3 元/月 或 30 元/年     | 核心订阅，成本极低（人均 50MB）          |
| 回忆录成书（PDF/纸质） | 100–300 元/本        | 按需印刷对接，高情感溢价，预计转化 1–2%      |
| 导出额度          | 免费 3 次，分享/关注/看广告解锁 | 流量主广告（UV≥500 可开通）+ 公众号导流    |
| 流量主广告         | —                  | 兜底性收入，日活一两百的工具小程序月收益约几十到几百元 |

### 阶段三：规模化期（日活 > 1 万）——数字纪念与生命服务

旗舰业务：**数字纪念馆**（也是全案利润率最高的业务线）。人在世时档案是工具，身后档案转为纪念空间——"数字化安葬"。

| 产品 | 说明 | 定价（拟） |
|---|---|---|
| 数字纪念馆 | 逝者档案转为家族纪念空间：人生陈列（文字/照片/录音）、亲友小范围共享或完全开放瞻仰、献花点烛留言（去迷信化设计） | 数据维护费 100–300 元/年 |
| 长周期套餐 | 10 年/20 年一次缴清享八折，仅对标线下骨灰存放柜数万元费用的零头 | 20 年约 2,000–5,000 元/户 |
| 人生短片 | 老照片 AI 修复+动态化+旁白配音，3–5 分钟"人生电影"（显著标识 AI 生成） | 单部 99–299 元 |
| 场景模板系列 | 同一成书引擎换模板：宝宝成长册、金婚纪念册、恋爱时光机等全生命周期纪念品 | 按次/按册 |

**B 端渠道是数字纪念馆的获客命脉**：与殡仪馆、公墓、白事服务商分成合作（介绍一单分 20–30%）。数字纪念馆不替代公墓，而是公墓的增量销售话术（"物理墓位+数字纪念馆"打包），可谈渠道联营。

其他：家族协作版（多人共编一册）、AI 深度访谈模式、语音朗读传记（TTS）、出版社合作。详见《技术升级方案》。

### 收入情景测算（阶段二稳态，注册用户 5 万、日活 2,000）

| 情景 | 云备份订阅                    | 成书转化   | 月收入估算        |
| -- | ------------------------ | ------ | ------------ |
| 保守 | 付费率 2%（1,000 人 × 30 元/年） | 0.5%/月 | 约 1,500 元/月  |
| 中性 | 付费率 5%（2,500 人）          | 1%/月   | 约 5,500 元/月  |
| 乐观 | 付费率 8% + 广告              | 2%/月   | 约 15,000 元/月 |

> 上述均为估算值，实际以运营数据为准。关键在于：**成本曲线极其平缓**（1 万用户月成本约 100–300 元），只要覆盖一点订阅收入即可持续运转，属于"小而美、很难死"的生意。

**数字纪念馆的 20 年长尾**（阶段三启动后）：纪念存量只增不减。按 1,000 座纪念馆 × 年均 150 元维护费 ≈ 15 万元/年的稳定存量收入起步，随时间累积；数字存储边际成本近零，此业务线毛利率超过 90%。

## 五、增长策略

1. **内容营销**：公众号「笑卿微道」持续产出"口述史方法/家族故事"内容，软性导流
2. **产品自传播**：导出册子带小程序码；"帮爸妈建档案"节日节点营销（春节/重阳/母亲节父亲节）
3. **家庭裂变**：档案浏览可分享给家庭成员，一册档案天然触达 5–20 个亲属
4. **渠道合作**（阶段三）：社区养老服务中心、老年大学、地方电视台情感栏目；**殡葬 B 端渠道**（殡仪馆/公墓/白事服务商——数字纪念馆在丧事现场的成交渠道，见阶段三）
